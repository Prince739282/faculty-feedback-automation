
# Faculty Feedback Automation System

## About the Project
Faculty Feedback Automation System is a web-based project that helps students give feedback about their faculty members and subjects.

The project aims to make the feedback process easier and reduce paperwork. It has separate dashboards for Students, Faculty and Admin.

## Features
- Login and Registration pages
- Student Dashboard
- Faculty Dashboard
- Admin Dashboard
- View available feedback forms
- Display feedback status
- Simple and user-friendly interface

## Technologies Used
- React.js
- JavaScript
- Tailwind CSS
- React Router
- Node.js and Express.js (planned)
- MongoDB (planned)

**Note:** The current version is frontend-based and uses sample data. Real login authentication, database connection and feedback storage are not implemented yet.

## Run Project Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Prince739282/faculty-feedback-automation.git
   ```

2. Open the project folder:

   ```bash
   cd faculty-feedback-automation/frontend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the project:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal.
